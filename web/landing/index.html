The sandbox

Each agent works on its own workstation

They can browse, edit files and run code. They cannot open anyone else's workstation.

Isolated

Separate from your laptop

One workstation per person. It cannot see your laptop or another tenant.

Ready in seconds

Self-hosted · MIT

Deploy it yourself

  • The hosted plan runs this same public code.
  • Docker for a trial, CubeSandbox microVMs in production.
  • Credentials and data stay on your side.
# containers on one host — for a trial run
$ git clone https://github.com/HuChundong/DshCloud
$ docker compose --profile build build
$ docker compose up -d
# a microVM per person — what production runs
$ docker compose -f compose.yml -f compose.cube.yml \
    --profile build build
$ docker compose -f compose.yml -f compose.cube.yml up -d
